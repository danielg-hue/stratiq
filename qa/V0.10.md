# StratIQ v0.10 verification

The original source archive passed integrity checks, and its 54 Python tests
passed before changes. The four SQL migrations in the deployed history were
replayed in an isolated PostgreSQL 17.12 container. The hosted instance uses
Supabase-managed components that the local container does not emulate.

Run the regression suites from the repository root.

```sh
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -v
bash qa/run-postgres.sh
```

## Assessment submission

The pending SQL grants the existing non-login `stratiq_assessor` role execute
access to one private security-definer function. The call inserts a snapshot,
50 assessments and existing-source citations, then seals the snapshot in one
transaction. It validates size, cutoff, score, coverage, licensing and evidence.
A retry with the same request ID and payload returns the sealed ID. A changed
payload for that ID fails. The worker still has no direct write grants and no
outcome access. The function can disclose validity of supplied company,
methodology and source references via database validation errors. Invoke it
from a controlled backend worker identity.

Separate worker transactions exposed a commit-time permissions failure in the
deferred evidence trigger. The pending migration gives that trigger a pinned,
schema-qualified security-definer evidence check and revokes direct execution.
The regression suite verifies this through transaction commit, including two
overlapping requests for the same ID. It also verifies role boundaries, missing
evidence, future evidence, restricted licensing, conflicting retries and
non-read-committed submission rejection. No production fixtures were inserted.

Automated approval blocked the live migration because of the privileged write
path. It is staged outside the applied migration directory. The live project's
four-migration history remains the reference until explicit authorization and
successful application.

## Research verification

The holdout comparator binds the protocol, model artifact and precomputed
predictions to SHA-256 digests. It rejects mixed splits and purges development
labels unavailable before holdout start. Its checks use synthetic data.
An independent custodian must register the digest before label release and
control holdout access. The comparator reports descriptive rank correlations.
It does not establish outcome-source authenticity or statistical significance.

The SEC adapter parses original Company Facts response bytes, records their
digest and preserves filing accessions and vintages. It uses the end of the
Eastern filing date as a conservative timestamp when the payload supplies
only a date. A real Apple response yielded 148 distinct assets vintages.
The September 2024 fiscal-year asset value was unavailable at 00:00 UTC on
November 2 and selected as USD 364.98 billion after the filing-date cutoff.
A SEC contact User-Agent is required by the adapter for repeatable ingestion.
This check covers one issuer and one concept. It does not validate a historical
universe, returns, corporate actions, delistings or a production ingestion job.

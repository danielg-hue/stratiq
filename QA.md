# v0.4 release gate — mandatory for every milestone
Before release: review cumulative diff and threat model; run regression, boundary, adversarial, provenance and applicable integration tests; remediate failures and rerun; record commands, results, limitations and outstanding defects. Never claim independent external review unless performed. Block production or empirical claims when critical controls remain open. Preserve versioned artifacts and test logs.

## This release
QA-001: reject all N/A until authorized industry applicability exists. QA-002: remove caller threshold; require 40 of 50 and at least half of each framework. QA-003: suppress nonfinite ratio, Altman, EVA and ROE results. QA-004: reject nonfinite Spearman inputs. Calibration requires feature timestamps no later than snapshot.
